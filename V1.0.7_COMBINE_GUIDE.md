# AutoCallManager V1.0.7 — V1.0.6 + Admin Panel

## What is combined
- V1.0.6 Android core: Smart Time, realtime Overview, screen-on/off/locked scheduled-call execution path, dual SIM, contact search, Gemini + versioned prompts, voice/TTS, notifications, history, reboot recovery, backup/restore, pause/resume/stop-all.
- Provided Admin Panel package: authenticated web admin, prompt catalog management, prompt version history, rollback, audit log, and optional server-side Gemini prompt testing.
- Android Settings now contains an Administration section with:
  - Admin Panel
  - Admin Catalog URL
  - Sync Prompts Now
  - Last Synced
- Android PromptStore can fetch enabled prompts from the configured `/v1/prompts` backend endpoint and cache the last successful catalog locally.

## Admin setup
1. Deploy `admin-server/` on Node.js 22.5+.
2. Set `ADMIN_BOOTSTRAP_USER` and `ADMIN_BOOTSTRAP_PASSWORD` before first start.
3. Put the deployed HTTPS base URL into AutoCallManager:
   Settings -> Administration -> Admin Catalog URL.
4. Open `Admin Panel` and sign in with the server-side admin credentials.
5. Edit/publish prompt versions in the web panel.
6. Tap `Sync Prompts Now` in the Android app.

## Security
- Admin authorization is server-side using session tokens.
- Prompt template edits create new versions; rollback is supported.
- Admin activity is audited.
- Do not expose the server over plain HTTP on the public internet.
- Do not put admin credentials or provider API secrets in the Android app source.

## Scope note
This combined release includes the Admin Panel capabilities present in the supplied Admin panel package. It does not add a separate multi-provider API-key vault or user/role-management system beyond the supplied implementation.
