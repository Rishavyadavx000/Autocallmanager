# AutoCallManager V1.0.8 Combine Guide

V1.0.8 combines the V1.0.7 RBAC Android/Admin base with the uploaded AI Voice consent layer and a server-originated AI Voice provider path.

## Core preserved
- Exact alarm based scheduled calls
- Screen-off/locked Activity-independent call path
- Dual-SIM selection/revalidation
- 12-hour time + editable seconds
- Prompt catalog + versioning/rollback
- Admin authentication/RBAC
- History/timeline and retry/watchdog logic

## New in V1.0.8
- `timezoneId` stored with each schedule; recurring calculations use the stored timezone.
- `executionMode`: `NORMAL_SIM` or `AI_VOICE`.
- Recipient consent + revoke + do-not-call safety gate for AI Voice.
- Consent audit trail.
- Admin AI Voice Safety panel.
- Server-originated Twilio + Gemini AI Voice path (configuration required).
- Explicit provider/AI call states.
- AI Voice API safety tests and consent tests.

## Production configuration required for real AI Voice
- `PUBLIC_BASE_URL` (public HTTPS)
- `PUBLIC_APP_KEY`
- `TWILIO_ACCOUNT_SID`
- `TWILIO_AUTH_TOKEN`
- `TWILIO_FROM_NUMBER`
- `GEMINI_API_KEY`

Do not place provider secrets in Android source, HTML, Git, backups, or client API responses.

## Compliance behavior
AI Voice compliance mode is STRICT: no consent or a do-not-call flag blocks the outbound AI Voice request.
