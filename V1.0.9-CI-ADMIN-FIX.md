# V1.0.9 CI/Admin Fix

This package is based on the V1.0.9 lint-fixed bundle.

CI fixes:
- Android and Admin jobs select a bundle only when BOTH complete project trees are present.
- Explicit preference for COMPLETE-COMBINED-FINAL, then COMPLETE-LINT-FIXED.
- Admin validation checks all required files before tests.
- Admin tests run as separate steps so the exact failing suite is visible.
- Server logs are printed automatically when a test fails.
- Test logs are uploaded as a CI artifact.
- Provider-safety test explicitly clears provider environment variables.

No lint suppression/baseline was introduced.
No Android call behavior or Admin safety policy was weakened.
