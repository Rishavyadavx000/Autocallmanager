# AutoCallManager V1.0.9 GitHub Upload

Use the contents of this package as the repository contents. Do not upload the ZIP file as a single file and expect GitHub Actions to execute files inside it.

Recommended: extract this package, then upload/commit the extracted files to the repository root.

The workflow is bundle-aware: it can run when the Android/Admin project is at the repository root, or when a valid project bundle ZIP is present in the repository.
