# AutoCallManager V1.0.6

## Smart Time
- Current device time auto-fills the schedule wizard.
- Direct text entry for hour, minute, and second.
- +/- controls retained.
- Explicit AM/PM selection.
- Live device clock and live selected-time preview.
- NOW, +1 MIN, +5 MIN, +10 MIN shortcuts.
- Same-day past-time validation.

## Overview
- Reworked Overview into active/today/success/failed metrics.
- Added today success-rate bar and pending count.
- Added recent activity feed using real history events.
- Added last-sync timestamp.

## Compatibility
- Version 1.0.6 / versionCode 106.
- Existing schedules remain timestamp-based in epoch milliseconds.
- Prompt/Gemini architecture retained.
- Admin Panel remains excluded.
